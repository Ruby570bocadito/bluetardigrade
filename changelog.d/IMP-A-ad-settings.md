Active Directory settings are now editable over the API (AD-6/SET-1 engine side): GET/PUT /api/settings/ad and the "Probar conexión" probe at POST /api/ad/test let an administrator review, validate, test and hot-swap the connector configuration without editing YAML by hand or restarting the engine. Every change is validated with the same rules the -ad loader applies, the password is written to its own SEC-2 envelope (never into the YAML, never logged or echoed), hand-edited config files refuse API overwrites with 409, and each commit leaves an audit line with the changed field names. The connector now reports the work-hours window (work_start/work_end/work_days) alongside its posture thresholds, ready for the logon analysis when WEF telemetry arrives.
