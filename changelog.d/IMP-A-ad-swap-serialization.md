- The AD settings PUT (AD-6) now completes the connector hot-swap inside the same serialized write that commits the file: overlapping saves publish connectors in the order they commit, the engine can no longer serve a configuration the committed file does not describe (SEG-A ronda 16 data race and lost update), and a swapped-out connector can never be left running with no owner.
- The PUT response now reports the resolved swap outcome — reload_pending false with last_reload_at and, on failure, last_reload_error (the committed config still applies on restart) — instead of announcing a pending reload; a GET served while a swap runs still shows reload_pending true.
