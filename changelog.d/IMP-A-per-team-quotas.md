- The engine now partitions its shared bounded detection state per host (v1.1 "cuotas por equipo"): the threshold and beacon key tables admit at most 2048 keys per host (25% of each table), existing keys of a saturated host keep counting and firing while only new ones are refused, and dead evidence is reclaimed before a refusal — a noisy machine can no longer wash out the shared tables the others report into.
- View-ring rotation is now counted per host: when a noisy host's records wash recent entries out of the in-memory rings, /api/stats reports ring_dropped_events/ring_dropped_alerts totals plus a bounded quota_top_hosts list (top 8, merging ring rotation and per-detector refusals), and /metrics serves the same totals as label-free counters; with -store attached the durable history is untouched either way.
- `sf-engine doctor` now validates known-software.yaml with the engine's own parser: a malformed file is reported as the startup-fatal error it would be, a valid one reports its entry count, and an empty one warns before the list silently guards nothing.
