- The console gains a Settings page (SET-1) with the sections the product names: General, Ingest, Active Directory, Integrations, Notifications, Accounts and Appearance. Sections whose configuration has no write API yet say so and show the real signal instead (enrollment state, SQLite store, webhook and SIEM delivery counters, the effective session); the language and theme preferences are editable in place.
- The Active Directory section is the first real settings surface (AD-6): it edits the connector configuration against the new engine API — connection, service account, sync window, OUs, thresholds and work hours — with a "Test connection" button that opens the connector's own TLS transport, performs the bind and shows what the service account can actually read (users, groups, computers, OUs) before anything is committed. Only the changed fields travel on save; the engine validates with its own loader rules, hot-reloads the connector and leaves one audit line per change.
- The service-account password is write-only: it is typed, sent to its own credential envelope and never shown, echoed or stored in the configuration; the page only reports whether an envelope exists. A drifted `-ad` file (hand edit) is protected by the engine's 409 and the page surfaces it verbatim.
