- Nightly fuzzing now covers every Go fuzz target in the repository through a discovery-generated job matrix (5 minutes per target, ten jobs in parallel) instead of a single hard-coded one; a new fuzz target anywhere in the tree joins the nightly rotation automatically, and a crashing input is preserved as a run artifact for triage.
- The ingest handshake's first line (AUTH/ENROLL) is fuzzed nightly: the AUTH/ENROLL classification and the enrollment line parsing are pinned against arbitrary bytes, refusing anything that is not exactly "ENROLL <token> <host>" or "AUTH <credential>".
