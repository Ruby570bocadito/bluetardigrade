- **A silent connection can no longer park the TLS ingest listener.** Past the 512-connection cap the engine answered "connection limit reached" from the accept loop itself; over TLS that write runs the handshake, which waits for a ClientHello with no read deadline, so one mute peer beyond the cap stopped every sensor from connecting. The refusal now runs off the loop with a deadline in both directions, bounded to 64 pending refusals.
- **The Windows rule pack ignores case, and encoded PowerShell is caught in every spelling.** Image names, paths and registry keys are case-insensitive on Windows, but 69 conditions compared exact bytes: `WMIC.exe`, `reg SAVE hklm\sam` or `COMSVCS.DLL` raised nothing. `rules/windows/` now uses the `i*` operators, with two new ones, `ineq` and `inot_in`. The encoded-command rules accept any prefix PowerShell accepts (`-e`, `-ec`, `-enco`…, `-w`/`-win` for the hidden window), `/` and Unicode dashes, and `pwsh.exe`; `-Encoding` stays out.
- **A threshold rule at its key quota recovers when its keys expire.** A rule grouped by source address that once reached 2048 keys never counted a new address again, because nothing purged its expired keys. They are purged (at most once a second) before a new key is refused; live keys are still never evicted.
- **Slow history queries no longer stall detection.** The SQLite store shared a two-connection pool between the API readers and the detection loop's inserts; two slow scans held both. Writes now have a connection of their own and readers a pool of four.
- **Domain sign-in resolves the role from the account that authenticated.** The post-bind search matched `sAMAccountName` OR `userPrincipalName`, so a user whose UPN prefix was another account's name could receive that account's groups. The search keys on the attribute the typed form names, refuses an ambiguous result, and refuses a `DOMAIN\user` prefix that is not this directory (set `domain:` in the config when the NetBIOS name differs from the first DNS label).
- **The console reopens the live stream after a non-200 answer.** A 502 from the proxy while the engine restarted (or a 401) left the `EventSource` closed for good: stats kept updating but no new alert appeared until a reload. It is recreated with backoff.
- **The ETW sensor never opens images on another machine, and bounds hashing time.** The process-start event waits for the image hash; a binary run from a slow share held that thread and everything queued behind it, and made SYSTEM authenticate against the host in the path. UNC paths are no longer hashed or YARA-scanned, and a single hash gives up after five seconds.
- **Privileged directories are created restricted and a foreign one is refused.** `install.ps1 -Server` and `sf-etw -Install` wrote into `ProgramData` folders any local account could have prepared (a planted toolchain later run elevated, or an entry of its own on the folder holding the tokens). The server root and the sensor data directory are now created with their final ACL, and an existing one is accepted only if its owner and every entry are SYSTEM or Administrators.
