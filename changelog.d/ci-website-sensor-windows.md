- **CI builds the landing page and runs the sensor tests on Windows.** The new `website` job installs `website/` from its lockfile, lints it and runs `next build` on every push and pull request: the landing page had been failing TypeScript and ESLint on main without any job noticing. The new `sensor-windows` job runs `cargo test --locked` natively on a Windows runner, the only place where the Windows-only modules of the sensor (collector, transport, enrollment, service) link and their tests run; until now CI only type-checked them through the cross-check, which is how a YARA worker test that failed on every Windows host stayed green.
