- **Console password questions on their own lines.** The two password questions of `sf-console -AddUser` (and of the `sf-start` first-account flow) left the prompt mid-line, and a line without its newline can stay buffered until Enter under Windows PowerShell, which wraps a native command's stderr line by line — the operator typed blind without even seeing the question. Each question is now a whole line of its own (`Contraseña para …:`, `Repite la contraseña:`), flushed before the typing starts; the typed characters stay hidden, a piped password is still read once, and the failure messages are unchanged.
