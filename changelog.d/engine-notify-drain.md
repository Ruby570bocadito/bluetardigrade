- **An alert queued at shutdown or at a channel change is no longer lost untried.** A notification worker whose context was cancelled in the same instant it popped a frame (Go's select picks uniformly between ready cases) counted that frame as dropped without any delivery attempt, although it had been queued before the shutdown and the drain promises every queued frame one best-effort try. Saving the notification settings in the console swaps the running channels the same way, so the alert in flight at that moment could vanish too. The popped frame now opens the drain under the same budget. `TestLiveSwapsWithoutLosingTheQueue` failed 45 times in 500 runs on Windows because of it (none in 1,000 now), and a deterministic test pins the case.
