- **Elasticsearch and Splunk deliver alerts again.** Since the boot-file split of `run.go` (088eaaa), a short variable declaration inside `startElastic`/`startSplunk` shadowed the returned sink: the engine announced `elasticsearch on …` / `splunk hec on …` and started the workers, but the alert loop received `nil` and never handed them an alert, so both sinks stayed at 0 sent / 0 failed / 0 dropped without a single error line. The sinks are assigned again and a unit test pins that a configured sink reaches the alert loop; `e2e_siem.sh` (both sinks, credentials, daily index, failure accounting) passes against the real binary. `v1.0.0-rc1` is not affected; installs that tracked `main` after 2026-10-21 are.
