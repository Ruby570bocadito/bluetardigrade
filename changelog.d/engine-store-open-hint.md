- **A damaged store file says what to do.** An engine started with `-store` on a file that is not a SQLite database (damaged, or another program's file) stopped with SQLite's own words only ("PRAGMA journal_mode=WAL: file is not a database (26)"). The fatal start now adds a line with the way out: move the file aside so the engine starts a new store, or restore it from a backup; the same applies to a malformed database image. Any other store error keeps its message unchanged.
