- **Engine and collector fixes from a full pass on a Windows 11 host.** Known-software image globs now match with `path.Match` on every platform: on Windows `filepath.Match` only treats `\` as a separator, so after the `\`→`/` normalization a `*` crossed directories and `C:\Users\*\AppData\Local\Vendor\agent.exe` also tagged `C:\Users\bob\Downloads\x\AppData\Local\Vendor\agent.exe` as known, silencing its never-seen-process alert (and any rule with `exclude_known_software`). `Store.Close` closes the read-only handle of the database query surface too, which kept the SQLite file locked on Windows, and a store that cannot be opened names its path in the fatal error. The collector accepts files that start with a UTF-8 byte-order mark (Windows PowerShell 5.1 `Set-Content -Encoding UTF8`, or a pipe from a UTF-8 console) and refuses UTF-16 input (`Out-File`, `>`) with the conversion command instead of `line 1: expected a JSON object`. `engine scenarios replay` keeps each event's own host (plus the per-run suffix) and looks for the expected alerts on all of them: the two cross-host chains could not complete on a clean engine and only passed on leftovers of earlier replays. The `-forensic-dir` help and the operations guide now describe the real default (`./forensics` of the working directory, or `<engine dir>/../forensics`).
