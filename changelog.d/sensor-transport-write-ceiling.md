- **The sensor can no longer stall forever on a wedged engine connection.** The event stream restored pure blocking semantics after the AUTH/TLS handshake, so an engine that accepted the TCP connection but stopped reading (zero window, silently dead path) blocked the delivery thread inside `write_all` indefinitely: the stop flag was never consulted, a shutdown lost the in-flight line and everything still queued instead of spilling it, and the heartbeats — which ride the same queue — froze, so the engine would raise false "sensor sin señal" alerts for a live sensor. Event writes now carry a 30 s ceiling (reads stay blocking; the sensor never reads after the handshake): a wedged write fails, `send_line` drops the socket, honors the stop flag and the queue spills to the spool as documented. Enrollment also flushes the credential file to disk (`sync_all`) before the atomic rename, so a power cut in the enrollment window can no longer leave a torn credential that bricks every later start after the enrollment token is gone.
