- **Windows launchers deliver external notifications.** `sf-start`, `sf-console` and `start-engine` pass `-notify tools\config\notify.yaml` to the engine whenever the operator created that file — until today the flag existed but nothing on Windows ever handed the config over, so mail and Telegram could never arrive from a stock install (the missing piece behind the "critical alert, no warning" report). `notify.example.yaml` documents the channel schema at the repository root, and `sf-engine doctor` gains an external-notifications check that validates the file with the same fail-loud loader the engine uses — without sending anything and without disclosing secrets (only scheme://host or an `<endpoint>` placeholder reaches the report).
