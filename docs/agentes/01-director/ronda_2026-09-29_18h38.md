## Riesgos detectados

### Prioridad ALTA (bloqueantes o degradan el producto de forma visible)

1. **[open source / marca] Dependencia privada `z-ai-web-dev-sdk` con mención de marca de IA en el código.**
   - Dónde: `web/console-service/package.json:11` (`"z-ai-web-dev-sdk": "^0.0.18"`), `web/console-service/analyst.ts:1,5,77,81` (comentario, import y uso), `web/console/README.md:42` (documentación).
   - Impacto doble: (a) incumple la regla de cero menciones de marca de IA (dependencia, código y docs citan explícitamente el SDK); (b) el paquete no está en el registro público, así que `bun install` falla para cualquier tercero y la consola completa queda inservible fuera del entorno original — esto es, a todos los efectos, una dependencia rota en producción.
   - **Asignado a: Implementaciones** — sustituir el backend del analista por un proveedor accesible públicamente configurado por variables de entorno (p. ej. endpoint compatible con API openai con `ANALYST_BASE_URL`/`ANALYST_API_KEY`/`ANALYST_MODEL`), con degradación elegante cuando no haya credenciales (el panel ya sabe reportar error; que el resto de la consola siga funcionando sin él, como ya ocurre). **Pulimiento** barrerá cualquier resto de mención que quede tras el cambio.

2. **[bug build] `Makefile`: recetas con espacios en vez de tabs → `make` falla con "missing separator".**
   - Verificado sobre el blob de git (`git show HEAD:Makefile`), no es un artefacto del checkout: todas las recetas (`run-engine`, `build`, `test`, `build-sensor-windows`, etc.) tienen 8 espacios iniciales.
   - Impacto: el quickstart del README (`make run-engine`, `make run-devsensor`) y la puerta de entrada de cualquier contribuidor están rotos tal cual el repo se distribuye.
   - **Asignado a: Bugs/Seguridad** (es una rotura funcional verificable, no solo estética). Corrección trivial + verificación con `make -n run-engine` y `go build ./...`.

3. **[bug visual] Constantes ANSI rotas en `internal/alert/alert.go:22-28`.**
   - Todas las constantes valen `"\033"` sin los parámetros SGR (deberían ser `"\033[0m"`, `"\033[1;35m"`, `"\033[1;31m"`, ...). Consecuencia: `cReset` no resetea nada, y cualquier severidad imprime el mismo escape invisible — los colores de alertas en consola no funcionan. Patrón de corrupción idéntico al del Makefile (algo strip-ó las secuencias entre corchetes), lo que sugiere revisar el toolchain de edición para evitar recidivas.
   - **Asignado a: Bugs/Seguridad**, en la misma pasada que el Makefile.

4. **[bug funcional] Hot-reload de reglas sobre ruta no resuelta en `cmd/engine/main.go:149`.**
   - El arranque resuelve `rulesPath` (flag → `./rules` → ruta relativa al exe), pero el ticker de recarga llama a `engine.Reload(*rulesDir)` con el valor crudo del flag. En el escenario instalado (`sf-engine.exe` arrancado desde cualquier CWD, que es como lo deja `install.ps1`), el reload de cada 15 s apunta a `./rules`, falla en silencio (`err == nil` guarda el mensaje) y las reglas nunca se recargan. El correlator, en cambio, recarga sobre `seqPath` ya resuelto — la inconsistencia confirma el descuido.
   - **Asignado a: Bugs/Seguridad.** Fix: reusar `rulesPath`; añadir test del resolver de rutas si es barato.

### Prioridad MEDIA

5. **[seguridad de red] API del motor sin autenticación y enlazada por defecto a todas las interfaces (`:7778`).** El README la describe como "local read-only API", pero `:7778` escucha en 0.0.0.0: en una LAN cualquiera puede leer telemetría sensible (usuarios, hosts, líneas de comando). Propuesta: default a `127.0.0.1:7778`, opción explícita para bind remoto y, si el acceso remoto se soporta, token compartido por variable de entorno. **Asignado a: Bugs/Seguridad** (el cambio de default es pequeño; el token puede ir a ronda posterior).

6. **[seguridad de red] Puerto de ingest `:7777` sin autenticación.** Cualquier proceso/hosts capaz de alcanzar el puerto puede inyectar eventos NDJSON y fabricar alertas (veneno de datos en el canal que alimenta al analista). Aceptable para v0.1 monomáquina; **documentar el riesgo en el README** y planificar handshake con token compartido antes de que `-Firewall` lo abra a redes reales. Asignado a: Bugs/Seguridad (documentación ya, auth en 1-2 rondas).

7. **[seguridad web] `console-service` con `cors: { origin: '*' }` (`index.ts:21`).** Cualquier página web abierta en el navegador del operador puede conectar al socket de `localhost:3003` y leer la telemetría completa. Restringir el origen al del propio Next (o lista corta desde `NEXT_PUBLIC_CONSOLE_URL`). Asignado a: Bugs/Seguridad.

### Prioridad BAJA

8. **[docker] El `Dockerfile` no copia `sequences/`**, así que el correlator no funciona en contenedor (solo `rules/`). Una línea `COPY sequences/ ...` + flag `-sequences` en el CMD. Asignado a: Bugs/Seguridad (trivial) o Pulimiento.
9. **[reproducibilidad] `.gitignore` ignora `sensor/Cargo.lock`.** En un binario lo correcto es versionarlo. Asignado a: Pulimiento.
10. **[higiene] `docs/assets/{cover.html,diagram_arquitectura.html,diagram_tracer.html}`** son fuentes de trabajo de los diagramas (los PNG y el PDF ya están renderizados). Decidir si se mueven a un subdirectorio de fuentes o se retiran del repo; en un open source de producción pesan como ruido. Asignado a: Pulimiento (decisión documentada, sin prisa).
