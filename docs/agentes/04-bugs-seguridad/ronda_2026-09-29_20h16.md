## Aporte efectivo: la guía

### Contenido

La guía (`docs/agentes/GUIA-VERIFICACION.md`) fija como estándar en una línea: *un hallazgo de contenido solo se acepta como real si queda demostrado con un conteo o una inspección de bytes sobre el blob; lo que muestra el canal de display NO es evidencia*. Y la desarrolla en cinco secciones:

1. **Artefacto A — el canal de salida sanea secuencias tipo ANSI:** documentado con el caso histórico 18h52 (el hallazgo #3 del Director refutado; el "patrón idéntico" Makefile/alert.go era coincidencia con causas opuestas) y con el protocolo de reproducción.
2. **Artefacto B — el editor corrompe tabs→spaces en Go:** recidivas citadas (`1e2c931`, rondas 19h14/19h49) y el protocolo obligatorio de cierre (`gofmt -w` tras toda edición; `gofmt -l .` vacío antes de todo commit y tras todo rebase).
3. **Chuleta de recetas:** tabla de comandos (conteo sobre blob con `git show | grep -c`, tabs vs espacios con `grep -cP`, bytes con `od -c`, display a prueba de saneo con `base64`, totales con `wc`), con la regla transversal de que la salida para humanos es pista, nunca veredicto.
4. **Árbol de decisión** ante un hallazgo de "corrupción" o "contenido desaparecido", en cuatro pasos, empezando siempre por el conteo sobre el blob.
5. **Registro de aplicaciones:** la trazabilidad de cuándo el estándar evitó o detectó errores reales (18h52, 19h28, 19h32, 20h14).

### Evidencia reproducida en vivo durante esta ronda

La guía no documenta de oído: durante la ronda se reprodujo el artefacto A tres veces con protocolo completo. (a) Sobre una línea de prueba con `[0m]`/`[31m` literales, el display de `cat` las ocultó mientras `grep -c` daba 1 y 1 sobre los bytes; (b) sobre el blob real de `internal/alert/alert.go` (línea 27), el display de `grep -n` mostró `cReset = "\033"` sin el corchete, mientras `od -c` probó los bytes íntegros `\t c R e s e t = " \ 0 3 3 [ 0 m " \n`; (c) los conteos del estado actual quedaron fijados para rondas futuras: `alert.go` → `grep -c '\[31m'` = 1 y `grep -c '\[0m'` = 1; `Makefile` → `grep -cP '^\t'` = 19 y `grep -c '^        '` = 0 (el fix de la 18h52 sigue en pie). Este triple registro —texto de prueba, blob real y octal dump— es el formato que la guía exige para cualquier veredicto de contenido.
