```go
// internal/siem/siem.go (añadidos; requiere import "net/url" y "errors")
// EndpointLabel reduces a sink URL to scheme://host so logs and the
// startup banner never carry path, query or userinfo (which operators
// legitimately embed for basic-auth clusters).
func EndpointLabel(raw string) string {
        u, err := url.Parse(raw)
        if err != nil || u.Host == "" {
                return "<endpoint>"
        }
        return u.Scheme + "://" + u.Host
}

// redactedErr strips the transport wrapper from HTTP errors so the
// request URL never reaches the log; only the underlying cause is
// kept, mirroring the webhook and notify connectors.
func redactedErr(err error) error {
        var ue *url.Error
        if errors.As(err, &ue) && ue.Err != nil {
                return fmt.Errorf("receiver endpoint: %w", ue.Err)
        }
        return err
}
```

```go
// internal/siem/splunk.go:129
```

## O1 — Guard de esquema `http`/`https` (pregunta explícita de 02, §5): recomendación ADOPTAR

El transporte `http.Client` rechaza `file://` por diseño del cliente, pero **tarde, por entrega, y con ruido de reintentos** — el modo de fallo "el check que no falla, miente" en versión lenta. Una línea por sink en la construcción (`NewElastic`/`newSplunk`) con `log.Fatalf` al arrancar si `u.Scheme` no es `http`/`https` iguala el contrato FATAL de la casa (`-beacons`/`-thresholds` malformados mueren con exit 1): un flag mal escrito (`-elastic file:///...`) hoy significa "sink que no entrega nada y quema reintentos en silencio operativo"; mañana debe significar "el engine no arranca y te dice por qué". `http://` **sigue permitido** (self-hosted/LAN legítimo; el aviso README ya lo documenta — fila O2 adoptada por 03-B en `58505b7`).
